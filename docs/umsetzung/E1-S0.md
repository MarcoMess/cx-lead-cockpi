# E1-S0 – Grundgerüst mit Startdaten: Übergabe

Branch: story/E1-S0-grundgeruest · Datum: 19.11.2026 · Ergebnis: Fertig

## Was gebaut wurde
Projekt nach Abschnitt 7 der Architektur als ein npm-Paket (TypeScript 5.9, React 19.3, Vite 8, React Router 8, Fastify 5.12, better-sqlite3 13, Vitest 5, Playwright 1.65). Schema mit allen Tabellen aus Abschnitt 4, Startdaten aus Abschnitt 8 des Konzepts samt Texten aus dem Clickdummy, die vier Befehle, Fehlerformat mit 404 `nicht_gefunden`, `GET /api/v1/gesundheit`, Navigation mit neun leeren Screens S1–S9 in den Farben des Clickdummys. Die Unterlagen liegen jetzt unter `docs/`.

## So prüft man es von Hand
1. `npm run einrichten` (ohne Internetzugang für Browser-Downloads: `PLAYWRIGHT_CHANNEL=chrome npm run einrichten`, nutzt ein installiertes Chrome).
2. `npm run dev`, dann http://localhost:5173 öffnen und die neun Bereiche durchklicken; `curl localhost:3000/api/v1/gesundheit` liefert `{"ok":true}`.
3. `npm test`.

## Abweichungen und neue Abhängigkeiten
- Versionen gegenüber dem Architektur-Entwurf aktualisiert; steht in `docs/architektur.md` 1.1, Abschnitt 12.
- `PLAYWRIGHT_CHANNEL` (optional) wählt einen installierten Browser für die Oberflächentests.
- `normalisiereFirmenname` steht schon in `src/server/regeln/dubletten.ts`, weil das Schema `name_norm` für die Startdaten verlangt. Die vollständige Dublettenprüfung bleibt E2-S4.
- `CLAUDE.md` und `README.md`: nur Versions- und Statusangaben der Unterlagen aktualisiert, Schnellstart ergänzt.

## Aufgefallen, aber nicht gebaut
- Die Startdaten-Branchen der Beispielfirmen (»Maschinenbau«, »Technischer Handel«) weichen in der Schreibweise von den Branchen des Rechercheprofils ab (»Maschinen-/Anlagenbau«, »Großhandel/technischer Handel«). So steht es in Abschnitt 8 des Konzepts; relevant für die Aufschlüsselung nach Branche (E9-S3).
- Kontaktversuche im Altbestand ohne bekannten Wortlaut tragen den Text »(Wortlaut im Altbestand nicht erfasst)«, weil das Datenmodell einen Text verlangt.
- Für Ostermann (geschlossen) und Wiesner (kein Interesse) setzen die Startdaten `geschlossen_am` auf 09.11.2026 bzw. 04.11.2026; das Konzept nennt kein Datum.
