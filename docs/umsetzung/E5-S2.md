# E5-S2 – LinkedIn: kopieren und Profil öffnen: Übergabe

Branch: story/E5-S2-kopieren-profil (baut auf story/E5-S1-ansprache auf) · Datum: 19.11.2026 · Ergebnis: Fertig

## Was gebaut wurde
In der Ansprache (S5) unter der Nachricht: »Betreff kopieren« und »Nachricht kopieren« legen den **aktuellen** Inhalt der Felder (auch nach Änderung) in die Zwischenablage und bestätigen es (»Betreff kopiert.«, »Nachricht kopiert.«). »Profil öffnen« ist ein Link auf das hinterlegte LinkedIn-Profil mit `target="_blank"`; ohne verifizierte URL fehlt er, stattdessen steht der Suchhinweis »Vorname Nachname, Firma« mit »Suchhinweis kopieren«. Geht die Zwischenablage nicht, sagt das Cockpit, wie man von Hand kopiert. Kein Code spricht LinkedIn an; es gibt keine Schnittstelle und keinen Serveraufruf dafür.

## So prüft man es von Hand
`npm run dev`, anmelden, »Ansprache« → »Ansprechen« bei Simone Gruber → »Betreff kopieren«, »Nachricht kopieren«, »Profil öffnen«. Für Ammann: Vorführleiste »Nächster Werktag«, »Agent meldet sich«, im Eingangskorb Ammann freigeben, dann in der Ansprache öffnen.
