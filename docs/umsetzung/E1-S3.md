# E1-S3 – Agenten-Simulator liefert den Beispiel-Lauf: Übergabe

Branch: story/E1-S3-agenten-simulator (baut auf story/E2-S3-lauf-anlegen auf) · Datum: 19.11.2026 · Ergebnis: Fertig

## Was gebaut wurde
`src/simulator/agent.ts`: Der simulierte Agent legt den Lauf ausschließlich über `POST /api/v1/agent/laeufe` mit dem Agenten-Schlüssel an (über `app.inject`, also durch dieselbe Zugangs- und Fehlerbehandlung wie eine HTTP-Anfrage). Erster Lauf: die vier Beispielvorschläge aus `beispiel-lauf.json`; jeder weitere: null Vorschläge mit »Keine weiteren belegten Treffer«. Schalter »API für den Agenten gestört«: Dann entsteht kein Lauf, die Ergebnisdatei liegt unter `GET /api/v1/sim/agent/ergebnisdatei`. Neue Vorführ-Adressen `POST /sim/agent/meldung` und `PUT /sim/agent`; `GET /sim/zustand` meldet zusätzlich den Zustand des Agenten. Die Vorführleiste hat jetzt zwei Zeilen mit »Agent meldet sich«, dem Schalter und einer Rückmeldung (auch bei Fehlern).

## So prüft man es von Hand
`npm run reset`, `npm run dev`, anmelden, in der Vorführleiste »Agent meldet sich« → »Der Agent hat 4 Vorschläge geliefert.« Ein zweiter Klick am selben Tag meldet, dass es heute schon einen Lauf gibt. Haken bei »API für den Agenten gestört«, »Nächster Werktag«, »Agent meldet sich« → Hinweis auf die Ergebnisdatei. Sichtbar werden die Vorschläge im Eingangskorb mit E3-S1.

## Abweichungen und neue Abhängigkeiten
- Keine neuen Abhängigkeiten. Der Simulator bekommt den Klartext des Agenten-Schlüssels aus `COCKPIT_AGENT_KEY` (neue Option `agentSchluessel` von `baueApp`).
- Der Zustand des Simulators liegt in den Einstellungen (`sim_agent_…`) und wird mit »Zurücksetzen« gelöscht.
- `tests/api/E1-S2.test.ts` #1 prüft das Datum jetzt über das Feld `heute`, weil `GET /sim/zustand` zusätzlich den Agenten-Zustand liefert; der Prüfinhalt ist unverändert.
- **Außerhalb der Story, sicherheitsrelevant:** `vite.config.ts` sperrt `data/`, `*.sqlite*` und `.env` für den Entwicklungsserver (Befund 1 der Prüfung E1-S1: die Datenbank war ohne Anmeldung über `/@fs/…` abrufbar). Geprüft: 403 für Datenbank und `.env`, Oberfläche weiter erreichbar.
